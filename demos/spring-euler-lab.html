RESEARCH 01

One State, Two Forces

Spring 不预先生成一条动画曲线。它只保存当前状态，然后从这一刻推算下一刻。目标在中途改变，或松手时注入新的速度，都不需要重新创建 easing。

SPRING FORCE

距离负责拉回。

离目标越远，恢复力越大；负号让力始终指向目标。

Fs = −k(pos − dest)
DAMPING FORCE

速度负责减速。

阻尼力与速度方向相反，持续带走系统能量。

Fd = −bv
state = { pos, dest, v, k, b }
Spring 的自然感主要来自状态连续。拖拽时改变位置，松手时保留速度，之后的运动就会自然接上。

RESEARCH 02

Semi-implicit Euler

两份实现都属于欧拉积分，但准确名称是半隐式欧拉：先更新速度，再使用刚更新的速度推进位置。

THE IMPORTANT ORDERdt = 0.004
// 1. old position + old velocity → acceleration
const a = k * (dest - pos) - b * v

// 2. acceleration → new velocity
v += a * dt

// 3. new velocity → new position
pos += v * dt

RESEARCH 04

Same Integrator, Different Time

蓝色玩具每次只前进固定的 4ms，一帧内可以补跑多次。橙色 ghost 每个渲染帧只运行一次，并把最大步长限制为 1/30 秒。它们都是半隐式欧拉，区别在时间策略。

FIXED 4MS

物理与刷新率解耦。

60Hz 一帧大约四步，120Hz 一帧大约两步。掉帧后补跑小步，轨迹更一致。

steps = ⌊elapsed / 4ms⌋
FRAME Δt

每帧只计算一次。

实现更短、成本固定。限制最大 dt 能防止爆炸，但掉帧时会丢失一部分真实时间。

dt = min(frame, 1/30)

Minimal Fixed-step Spring

Framework-free. The same function can drive position, scale, opacity, radius, or WebGL uniforms.

spring.js
const STEP = 0.004

function spring(pos, k = 290, b = 24) {
  return { pos, dest: pos, v: 0, k, b }
}

function step(s) {
  const a = s.k * (s.dest - s.pos) - s.b * s.v
  s.v += a * STEP
  s.pos += s.v * STEP
}

function frame(now) {
  const steps = Math.floor((now - simulatedUntil) / 4)
  simulatedUntil += steps * 4
  for (let i = 0; i < steps; i++) step(state)
  requestAnimationFrame(frame)
}
